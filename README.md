# exercicios-python

Título: exercicios-python

Identificação: Caue Rodrigo Goedert Da Silva, Dsm3 e Programação de aplicativo

Descrição: Coleção de exercícios práticos de Python desenvolvidos para fixar conceitos fundamentais da linguagem, como variáveis, condicionais, repetição e listas.

Tecnologia utilizada: Python 3.14

Como executar: Abra o terminal na pasta do exercício desejado e execute "python <numero>.py". Exemplo: "python 1.py"

Índice dos exercícios:

 Parte 1 — Variáveis, entrada e saída
 1.py : Exibe nome e idade
 2.py : Soma dois números
 3.py : Calcula a área de um círculo
 4.py : Converte Celsius para Fahrenheit
 5.py : Calcula o total de uma compra

 Parte 2 — Condicionais
 6.py : Verifica se um número é par ou ímpar
 7.py : Exibe qual dos dois números é o maior
 8.py : Verifica se um número é positivo, negativo ou zero
 9.py : Classifica a média do estudante em Aprovado, Recuperação ou Reprovado
 10.py : Verifica se a pessoa pode votar

 Parte 3 — Repetição com while
 11.py : Exibe os números de 1 a 10
 12.py : Soma números até digitar 0
 13.py : Pede senha até acertar
 14.py : Exibe a tabuada de um número
 15.py : Conta quantos números positivos foram digitados

 Parte 4 — Repetição com for
 16.py : Exibe os números de 1 a 20
 17.py : Exibe os números pares de 2 a 20
 18.py : Soma todos os números de 1 a 100
 19.py : Calcula o fatorial de um número
 20.py : Contagem regressiva de 10 até 1

 Parte 5 — Listas
 21.py : Exibe os itens de uma lista
 22.py : Soma todos os itens da lista
 23.py : Encontra o maior valor da lista
 24.py : Conta quantos itens são maiores que 10
 25.py : Exibe os itens da lista na ordem inversa
